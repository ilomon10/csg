M2-17: the character renderer drives the preview through the pixel pipeline (spec 003 REQ-PIX-001/010/030/031/034). The canvas drawing buffer is now the cell size; `resize(viewportCssW, viewportCssH, dpr?)` returns the integer CSS layout `{cellW, cellH, scale, cssW, cssH}` instead of resizing the drawing buffer (breaking for preview hosts). New: `setRenderSettings`, `prepareFrames` / `renderFrames` (exclusive export through the preview pipeline, restored afterwards), `readCell`, `cellTarget`, `pipelineStats`, `previewLayout`, `createCanvasPresenter`. The engine barrel now also exports the pipeline and sampler modules. Preview timing defaults to the export sample times of the clip's selection (REQ-ANM-018, AC-PIX-030.2).
