Add the M1 character renderer and assembly (spec 000 REQ-GEN-001/002, spec 001 REQ-CMP-002/013/033/037, spec 002 REQ-ANA-006/011, spec 004 REQ-ANM-018): `createCharacterRenderer` creates a `WebGPURenderer` (WebGPU, else WebGL2; `backend` reports which, `PIX_BACKEND_UNAVAILABLE` when neither works) with a simple preview scene; `createCharacterAssembly` applies `CharacterSpec` changes as diffs (tints as uniforms, part changes rebind only that part, a body change rebuilds the skeleton from the body's `characterSkeletonGroup` and a fresh clip player); `evaluatePose` poses a frame in the spec 002 order (sample, root motion, anatomy, ground offset, sockets) without per-frame allocation. The engine barrel now exports the public API including the contract types.
