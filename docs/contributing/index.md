title: Contribute

---

Thanks for contributing. The project is open source and runs on Markdown specs, so most changes start with a spec.

Start here:

1. Read `AGENTS.md` in the repository root. It holds the rules for every contributor, human or AI.
2. Set up your machine: [Development setup](./development-setup).
3. Learn the spec process: [Spec process](./spec-process).

Guides:

- [Adding parts](./adding-parts): add a character part as data.
- [Asset pipeline](./assets): licenses, Blender export settings, pack config and budgets.
- [Writing a shader node](./writing-a-node): add a node to the shader graph.
- [Testing](./testing): test layers, AC naming and golden images.
- [AI-assisted contributions](./ai-assisted-contributions): the policy for AI tools.

Every change must cite the spec IDs it implements. The pull request template asks for them.

Licenses: code is MIT. Assets must be CC0 or a compatible license, recorded in `ASSETS_LICENSE.md`.
