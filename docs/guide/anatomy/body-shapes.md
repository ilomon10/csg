# Body shapes

A body shape is a ready-made set of proportions. In Easy, and in the wizard's **Body shape** step, you pick one card and the character takes that shape. There are no sliders.

## The six shapes

| Shape | What it changes |
|-------|-----------------|
| Average | No change. The base proportions of your style. |
| Slim | A narrower torso, thinner limbs, and slightly smaller hands and feet. |
| Athletic | Broader shoulders and torso, thicker limbs, and a little taller. |
| Stocky | A wide torso, thick limbs, and shorter legs and height. |
| Tall | Taller, with longer legs and arms, and a slightly narrower torso. |
| Petite | Smaller overall, with smaller hands, feet and shoulders. |

The cards appear in this order: Average, Slim, Athletic, Stocky, Tall, Petite.

## Shapes build on your style

A shape changes the starting proportions of your current style, so the same card looks right on every style. Each shape sets all nine proportion values as one undo step.

For example, on Realistic, Stocky sets each value to its factor exactly. On Chibi, the torso starts wider, so the same Stocky card gives a torso width of 1.32 instead of 1.20.

Values stay inside the limits in [Anatomy](./index.md).

## Custom shapes

If your proportions match no card, the Shape group shows a selected **Custom** card. Choosing a card replaces the Custom values. Looking at a Custom card does not change anything. To set exact values, open the same character in Pro and use the sliders.

## Where to choose

- **Easy**: the **Body** category, in the **Shape** group.
- **New character**: step 3, **Body shape**, of the [wizard](../getting-started/new-character-wizard.md).
